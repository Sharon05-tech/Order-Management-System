# Order Management System (C++)

## Overview
A scalable backend Order Management System implemented in C++ using optimized data structures and object-oriented design principles.

## Features
- User and product management
- Priority-based order processing (Prime users first)
- Fast order search and retrieval
- Inventory stock validation

## Data Structures Used
- unordered_map for O(1) lookups
- priority_queue for efficient order processing
- map for sorted inventory handling

## Concepts
- Object-Oriented Programming
- Data Structures & Algorithms
- Time and Space Complexity Optimization

## How to Run
g++ main.cpp -o order
./order
